# Plan: media-loops — the gen1 media lane as kit workflows and loops

**Repo:** agnostic-router-kit (the plane surface lands once; the kit edition inherits it through the `workflow-plane` symlink and gains the loops, the doctor row, and its own port). **Source:** dev-decisions `main` at `8f67afb` — the merge of `feature/media-generation-lane`, which closed C0–C9 of `docs/plans/2026-10-08-media-generation-lane.md` with seven verbs (`media-gate`, `media-transcribe`, `media-speak`, `media-imagine`, `record-asr`, `record-media-runs`, `media-budget`) and left exactly one use case open: **F, the kit integration — "a `media` grant (`world.speak/transcribe/imagine`), so router loops can render — deferred to the kit; the trigger is a kit workflow that adopts media."** This wave is that trigger. **Composition law, the reading this wave keeps:** sys1 reads what the work says, sdm1 scores what the work measures, sem1 indexes what the work looks like, gen1 generates what the work needs heard and seen — and the engine's own rule holds on both sides of the seam: *media renders, the gates judge*. Nothing in this plan lets a media output decide anything; every verdict the lane produces is advisory until the calibration evidence says otherwise.

**The idea, stated once:** the kit can judge, score, index, and keep its diagrams anchored — but every deliverable it produces is silent and text-only, and the media lane that just landed in the engine has no consumer at all. The lane was built to feed two discipline loops and one verification gate, and the engine deliberately shipped none of them because they belong here: an ASR calibration loop that produces the evidence to lift the lane's `gen1_raw` eval-only tag, a media-budget loop that keeps audio-seconds spend inside a named budget, and a narrate workflow that renders a script to voice and verifies the render against its script. One grant, three workflows, one consumer leg, one producer — all batch-only, all default-off, all advisory. The first loop's output is the promotion evidence for everything the lane is still not allowed to do.

## Approach

Four laws from the engine's design decide every choice below, and each is inherited rather than re-argued:

1. **Batch-only.** A media call is a network round-trip; it happens between agent rounds, never inside an ask. The three workflows are deterministic tool-flow — no agents, no model calls of their own — the same shape as the tabular and diagram loops. The engine proves the law with a socket guard and a hook-source guard; this wave proves it with the probes' structural greps.
2. **Eval-only until calibrated.** Every row the lane emits is tagged `gen1_raw/<leg>`. `record-asr` is the lane's one gradeable exception — it round-trips the pinned `nar-s1` fixture into the shared feedback store under `asr_roundtrip` / `asr_faithful` / `gen1_raw/<leg>`, the exact join key `calibration` already reads. The asr-calibrate loop is therefore the lane's promotion engine, and it stops at producing evidence: lifting the tag is the owner's call, exactly as the engine's plan defers per-surface floors.
3. **Warn, never block.** `media-gate` exits 1 on gaps and 3 on all-refused, never 2 — a source guard proves `EXIT_BLOCK` is unreachable in `media.py`. No kit workflow converts a media verdict into a block; gaps are reported and escalated, and the run proceeds.
4. **Money per call, no cost field.** gen1 v1 telemetry carries duration and provider, not cost; duration is the proxy. The budget loop is the spend control, and the app-token `grantCeiling` is the second one.

On those laws, the wave is four capabilities:

1. **The bridge** (`world.media`): the tabular surface cloned for the media lane's seven verbs, with `--json` injected on every call. W0 adds that machine mode to the engine first — the media verbs currently print human prose (`media-gate: verdict gaps (3 line(s) differ…)`), and the semantic lane already walked this path when its kit bridge arrived (engine `3c61126`, "--json lines … (kit bridge)"). The pinned row shapes are the delegation contract between the two repos.
2. **The promotion engine** (`workflows/asr-calibrate.ts`): grades the pinned fixture per leg, compares against a named floor, escalates the legs that clear. Report-only; writes nothing in the engine.
3. **The spend loop** (`workflows/media-budget-watch.ts`): ingests gen1 telemetry into `media_runs.csv` (occurrence-keyed, idempotent) and forecasts next-day audio-seconds per provider through sdm1, degrading with a named reason rather than fabricating a band. Escalates on over-budget only.
4. **The render-and-verify workflow** (`workflows/narrate.ts`): speaks a script's lines through the engine's fail-open wrappers, assembles the seam's `audio_meta.json` from the engine's own accountable rows, and gates the render with `media-gate` — token agreement per line, WARN on gaps. Plus one consumer leg in `content-production`: the assembled draft gains an optional voice track behind the grant, absent grant = today's behavior.

## The workflows

**asr-calibrate** (`workflows/asr-calibrate.ts` — loop, batch-only, no agents):

1. **Grade.** `world.media("record-asr", { fixtures })` — the pinned fixture round-tripped through the live ASR leg, one row per provider tag. CLI absent, or every fixture refused, ends the loop fail-open by name: the store unchanged, the refusal verbatim, the conclusion honest.
2. **Read the floors.** Per leg: `n`, `accuracy`, `mean_agreement` against `floor` (default 0.9) and `minRows` (default 3). A leg clears when both hold. The loop reads the graded rows the verb just printed — it does not re-open the feedback store, and it never edits the engine's config or the `gen1_raw` tag.
3. **Report.** Per-leg table; cleared legs named as the promotion evidence; the rest named with what they lack (rows or agreement). Exactly one `escalate` when any leg clears — "these legs are calibrated; the owner decides whether gen1_raw lifts." `args: task` (default `asr_roundtrip`, the calibration task key — also the router-assignable arg), `fixtures`, `floor`, `minRows`.

**media-budget-watch** (`workflows/media-budget-watch.ts` — loop, report-only by law):

1. **Ingest.** `world.media("record-media-runs", { telemetry })` — gen1's telemetry sink into `tables/media_runs.csv`, occurrence-keyed so a re-run lands nothing twice. A missing sink ends the loop fail-open by name (the engine's own words: "run a speak/transcribe first").
2. **Forecast.** `world.media("media-budget", { "budget-seconds": budget })` — per-provider next-day band through sdm1; fewer than four recorded days degrades with the named reason; a declined forecast degrades to recorded stats with the forecast's error as the reason. `over` → the loop reports it and escalates once. Degraded never escalates — a named reason is information, not a crossing.
3. **Report.** Per-provider bands, the estimate against the budget, the degraded providers with their reasons. `args: budgetSeconds` (absent = report only), `scope` (comma-separated providers — the router-assignable arg), `telemetry`.

The daily cadence is the operator's, exactly as `npm run record:quota` is: `recorded_at` is the ingestion date, so a daily band needs a daily ingest. `tools/record-media-telemetry.mjs` + `npm run record:media` is that entry point — one `execFile` of the CLI verb, so the cron line lives in the repo's own vocabulary.

**narrate** (`workflows/narrate.ts` — one-pass, batch-only legs, no agents):

- **Verify mode (default):** `--script` + `--audio` (single file) or `--request`/`--meta`/`--project` (an existing render, seam mode) → `world.media("media-gate", …)` → verdict `pass`/`gaps`/`error` with per-line token agreement. `gaps` → report + one escalate (advisory; the engine's gate never blocks, so neither does this loop). A `--project` path-escape is the engine's refusal by name — the loop resolves nothing itself and passes the refusal through verbatim.
- **Render mode:** a request file of lines (`[{id, text}]`) → `media-speak` per line into `outDir` (voice/language/speed forwarded) → assemble `audio_meta.json` from the speak rows themselves (`id`, `path`, `duration_s` from the row's byte-measured duration, provider leg, `format`, `voice`, `request_id` — the seam's pinned dialect) → `media-gate` in seam mode. The loop composes the seam from the engine's accountable rows rather than shelling gen1's hyperframes route under the process grant: the rows are the accountability surface, and one grant is one thing to police. Writing the meta rides the default-on workspace-io grant.
- `args: script, audio, request, meta, project, outDir` (default `assets/voice`), `voice, language, speed, dryRun` (verify without rendering). Hand-launched by design — structured args, the tabular loops' posture.

**The consumer** — `content-production` gains one optional leg: after the reviewer's fix pass, when `world.grants().has("media")`, the assembled draft is spoken through `media-speak` and gated through `media-gate`, and the verdict rides the deliverable as an advisory line. Grant absent → exactly today's behavior (the `triage.ts` eval-head pattern). The leg never blocks.
