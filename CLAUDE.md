# agnostic-router-kit — house rules

This repo is the harness-agnostic edition: the router and roster are neutral
by contract. Nothing here may reference any harness's home directory, config
file, or CLI. The check that keeps it that way:

```
grep -rni "zcode\|~/.zcode" lib bin router roster.json templates | grep -v "^\S*: *\*"
```

must stay empty (the agnostic-distinction comment in CLAUDE-less files may
mention what this repo is NOT; code paths may not).

## Hard rules

1. **Never put a raw API key in `roster.json` or any tracked file.** Keys are
   env-var names in the roster; values live in the runtime `.env` (chmod 600)
   and nowhere else. `kit apply` warns on raw keys — treat the warning as a
   stop, not a note.
2. **Never hand-edit rendered outputs.** `router/` in the repo is source; the
   runtime under `~/.agnostic-router-kit/router/` is generated by `kit apply`
   (and by the dashboard's save-and-apply). Hand-edits there are lost.
3. **Dry-run before apply.** `kit apply --dry-run` first, every time.
4. **`kit doctor` after apply.** It checks the sys1 dependency, the tiers,
   the keys, and the service. Green or it didn't happen.
5. **Destructive operations** (force-push, history rewrite, deleting runtime
   state under `~/.agnostic-router-kit/`) need explicit user approval in the
   current turn.
6. **Default operation target is `master`** for this repo.
7. **The `/api/` block is operator-class.** App tokens act through `/v1`,
   scoped by ceiling, workspace and run ownership — never give an `/api`
   route to an app token, and keep it that way when adding routes.
8. **`POST /api/keys` is write-only by contract.** Values go to the runtime
   `.env` (chmod 600); a response may say whether a name resolves, never
   what was written.
9. **`copyRuntime`'s file filter carries the page shells by name**
   (`dashboard.html`, `setup.html`, `chat.html`). A new `.html` in `router/`
   must be added there or it never reaches an install.
10. **`awaitOwnerMs` defaults to 0** — escalations resolve immediately unless
   a spawner opts into the owner wait. Don't flip the default: existing
   callers depend on degrade-fast.
11. **The memory store is runtime state, never hand-edited.**
    `~/.agnostic-router-kit/memory/memory.jsonl` is the durable memory plane
    (JSONL, official MCP graph format). Mutate it through `kit memory`, the
    MCP server, or the router routes — a hand edit is lost the next atomic
    write, and a malformed line is skipped silently by design.

## Dependencies

- **sys1** (https://github.com/adelvillar1/sys1) — the decision-model service
  on 127.0.0.1:8400. Required by `judge.mode: fastino|cascade`; optional for
  `typesafe`. `kit doctor` checks it explicitly; the router fails open to
  `defaultWorkload` when it is down — requests never fail, they degrade.
- **TypeSafe Jev** — the escalation leg and the mixture's best-answer judge;
  key in the runtime `.env`.
