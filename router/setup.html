Let's get you routing.

The terminal steps are done — this page checks the chain and finishes the judgment half: keys, and connecting your agents. Everything below is the router's own verdict, live.

connect an agent

Any OpenAI-compatible harness — a coding agent, an editor extension, a script — talks to the router with three things: the URL, a token, and a ceiling (what that token may start). When one of its runs needs a human decision, the question appears in chat.

The router's token

Setup reads and writes through the operator token — router.config.json → localToken. It stays in this browser.
